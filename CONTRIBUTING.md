# Contributing

APLForever-Open welcomes reproducible, **WoW Forever / Hekili Forever-specific** feedback and proposed changes. It has a sole official maintainer: **@tkbiccay**.

Before submitting an APL, review the current public catalogue, chosen APL, pinned released Hekili engine, prior negative results and rollback. Keep each proposed APL complete in one independently importable file. Create a new versioned **Candidate** rather than rewriting a protected selected or reported-working APL. Document source, test conditions, toggles, accepted/refused action progression and three subsequent recommendations at the final fallback.

Use real **Forever** evidence; don't silently substitute Retail, Classic, SoD or SimulationCraft spells/APIs. Distinguish Static / Source-Native / Simulated / Reported / In-Game. Do not claim performance wins within noise or use CI alone to promote to Approved.

Please do not share personal information, confidential private-repo links, real account data, credentials or unredacted `/hek snap` captures. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

**Licence:** by contributing you affirm you have rights to submit original work under GPL-3.0-only, preserving any third-party copyright/licence notices. PRs are proposals; the sole maintainer chooses which official changes to accept.
