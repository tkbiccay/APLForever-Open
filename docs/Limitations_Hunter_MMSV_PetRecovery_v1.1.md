# Limitations — Hunter MM & Survival pet upkeep Draft candidates

1. Published Hekili Forever v0.11.0 supports source-observed main pet existence/death, enabled talent and client spell usable state, but the source helper world does **not** implement accepted Call/Revive spell effects or actual pet arrival; repeated recovery icons until arrival are **not validated combat casts**.
2. Lone Wolf decisions reflect actual selected talent. MM shipped Turret build uses Lone Wolf and intentionally plays petless; adding pet upkeep must not force a pet for these characters. Survival Melee shipped 51-point build lacks Lone Wolf and can legitimately want a pet. Alternate legal 51-point talent distributions used only for source guard testing, not player recommended PvE builds.
3. Native source-world accepted-cast equivalence uses source kit with a living pet and natural source Mana; it does **not** prove pet threat, damage, selection in the real UI, low-level unlock timing, cooldown manager, movement or 2/3+ target effectiveness.
4. Source base `revive_pet` can be 10 seconds and 100% base Mana without talents; 4 seconds/60% with 2 Improved Revive Pet. It is a safe **state recommendation**, not proof the player should channel it while an enemy hits them. Do not introduce hidden-health triage.
5. Player can disable individual spells via native Ability Require Toggle, which the APL must respect. No new manually required addon checkbox. Real build/level/gear, export, APL hash and `/hek snap` evidence needed before Approved. Drafts unselected, exact Current v1.0 files protected.
