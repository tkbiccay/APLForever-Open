## Mechanic and decision

Released Druid `barkskin` is source-registered ability ID **22812**, trainer unlock **level 44**, **60-second cooldown**, **15-second buff** and the engine's `toggle="defensives"`; class `now`/`handler` apply the registered Barkskin aura. Health-percent expressions can exist inside the simulation while actual Forever player health may be secret; the official wiki explicitly warns that `health.pct` then answers an unknown/full value. **Do not invent or rely on a real-life low-health read.** Class native code specifies effect but the released loop test world omitted Barkskin from its scripted kit/MAP; the test extended the fixture *only* with the real registered ID/learn and matching aura effect. This validates action execution and aura, **not actual mitigation, health-dependent trigger success or incoming-damage survival**.

The shipped `Guardian (wowsims.com).simc` references `barkskin,if=health.pct<=60`; in the bounded hidden-health source world it did not execute Barkskin. The protected v1.0/v1.1 custom files had **no Barkskin branch at all**. v1.1 already put Demoralising Roar under Defensives; preserve that higher mitigation priority. A single new **complete internal** `defensive_cooldowns` list is called after `mitigation` and before `keep_up`, with `toggle.defensives`, source `action.barkskin.known`, `action.barkskin.ready`, Bear Form, !Barkskin aura and actual `target.within5` guards. The full rest of the 25-action-line v1.1, including final Maul fallback, remains byte-identical; only those two source-backed lines were added. No cross-file runtime dependency or invented API.

**Trade-off:** this is **proactive when tanking in melee with Defensives ON**, not a proven intelligently timed emergency cooldown: 60-second availability might be spent before a later spike, a GCD can delay damage/threat or other tank upkeep, source target-within5 does not prove the player is tanking, and the source world cannot measure actual Barkskin damage reduction. If a client test reports inappropriate Barkskin use or threat loss, rollback to the exact protected v1.0, retain v1.1 archive, and refine in an independent candidate. Do not add Frenzied Regeneration's unmodelled health/Rage interaction without a verifiable trigger.
