# Guardian v1.5 Maul-first hypothesis — natural source Rage, 20 November 2026

**Equal P0 with Hunter BM.** Hekili Forever v0.11.0 exact published SHA `86b739cbc4e6afbcbc693c3790ee81197fc6234b`. Current protected Guardian v1.0 `Reported Working / Needs Retest`, full unselected v1.5 SHA `75de4388516e3e70cd77f292901c1205f1176dc3561ac9b54dac8fef6c2abcc2`. Both unchanged and source-verified. Official [Druid.lua](https://github.com/zmsl/hekili/blob/v0.11.0/src/Hekili_Druid/Druid.lua) registers the on-next-swing Maul action and Rage cost; using an APL `use_off_gcd` does not itself prove Maul executes. Existing [Guardian high-kit source test](../tests/native/aplforever_guardian_highkit_tail_v090_spec.lua) under v0.9.0 accepted and consumed a guarded v1.1 Maul queue after an *in-memory-only* reorder when three natural attackers were present; baseline high-kit reserve often below belief threshold. That older result is not proof for v1.5/v0.11.

**Hypothesis:** complete custom Guardian v1.5 currently calls `damage` before `rage_dump`. A limited **in-memory** change moves the original complete `rage_dump` list before `damage`, keeping every original Maul reserve predicate, forms, normal DPS chain, Demoralising Roar and fallback. This may permit high-kit naturally affordable on-next-swing queues, but could waste Rage/pre-empt primary abilities. Study source truth instead of assuming output improves.

**Actual test** published v0.11 source game loop with full Guardian v1.5 and independent in-memory reordering, 70s source-stable 2, 3 and 4 attackers, same seed 30417 and original talents/gear/learn ranks. Record max true Rage, conservative belief low bound, low-bound >=35 opportunities, three+ *real enemy swings*, exact source-accepted queue/strike/unqueue events, true Rage cost on Maul STRIKE, Primal Bite/Lacerate/Swipe accepted, any refusal/error/raise. No injected Rage, health, false source casts or guaranteed high kit. A new proposed APL is justified only if real Maul strike count/paid Rage improves without losing reliable core action and default/working comparators; otherwise retain v1.5. Even a source-genuine extra Maul is not DPS/TPS/survivability proof. **Actual v0.11.0 outcome — [run 44810733710](https://github.com/tkbiccay/APLForever-Open/actions/runs/44810733710): 3/3 native PASS, zero refused, zero engine errors, but NO POSITIVE Maul reserve case.** Complete v1.5 vs in-memory reordered v1.5 were byte-identical except list-call order. **Decision: REJECT a Guardian v1.6 Maul-order promotion at this time.** Neither candidate reached the existing v1.5 `rage.lo >=35` source reserve, so reordering could not plausibly trigger its high-kit Maul branch. The experiment proves source castability and no regression **in these states**, not that Maul can never execute; a high-Rage source-positive scenario and/or true live Rage+snapshot is required before promoting a new architecture. This is a **test coverage/resource belief boundary**, not reason to invent synthetic combat Rage, weaken safe reserves, or replace protected v1.0/v1.5. The older v0.9 v1.1 experiment used different source/architecture and cannot substitute as a v0.11 positive.
 Live guardian aggro, post-Roar, high-Rage and repeated-fallback remain separate final game gates.
