# Limitations — Protection Paladin v1.1 Draft

1. Client-reported `aggro` may be unavailable in real instances; player role can report DAMAGER even when built as tank; no pretend knowledge.
2. `mana.lo` is a conservative Belief estimate; may hold Holy Shield when true combat Mana suffices. It must still be tested with actual resource tails.
3. Published world block/charge/threat models do **not** prove real survivability or TPS. Real low-level talent unlock, gear, target swaps, dungeon AoE and final/fallback chain require additional tests.
4. User-disabled native Ability Require Toggle is a hard engine off-switch even if standalone APL does not ask for an extra checkbox.
5. Status Draft, preferred null, no in-game validated/Approved or justified working replacement.
