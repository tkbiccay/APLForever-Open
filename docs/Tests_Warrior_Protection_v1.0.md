## Safety and unresolved coverage

**The shipped-vs-custom difference does not establish a winner.** Shipped Protection generally used **Demoralising Shout and Shield Block** more here. But the experiment explicitly had **Defensives OFF** for both, and the custom APL places Shield Block in its toggle-gated survival list, so the absence in custom is **expected under this test configuration**. Shipped uses Shield Block despite that toggle in the source comparator; do not equate counts with survival. Under the custom APL, defensive mitigation is not yet tested **with Defensives ON**, at different level/target counts or an authentic in-game `/hek snap`. Threat, incoming effective damage, healer load, rage sustainability, uptime and practical output are not measured fairly. Shipped and custom also prioritise different Shouts/Thunder Claps; this must be compared using threat/mitigation evidence, not just number of casts.

**Bloodrage requires a separate health-cost gate.** The source class registers Bloodrage as gaining 10 Rage immediately plus ten one-second ticks but explicitly notes its **health cost is not simulated because real Forever player health is secret**. Shipped source worlds used Bloodrage; archived v1.0 APL includes no Bloodrage action. This is a valid **coverage difference**, not a safe instruction to add an unconditional resource generator. It could cause a Life-Tap-like repeated or life-cost unsafe fallback if health and intent are not observable. Do NOT fake health, prescribe autonomous Bloodrage, claim it is free, or move it under a cooldown category without verified controls. Reusable risk record [HEALTH-013](knowledge/lessons/CROSS_APL_TRANSFER.md).

**Approval restrictions:** No matched repeat seed sets, no in-game confirmation, source model lacks real threat/health/mitigation and exact client-facing Rage can be estimated/hidden. Shipped default is reference and fair comparator, not an architectural ceiling. This role has no reported-working or selected `preferred_apl` checkpoint to override. **No new Candidate, revision, current preference or rollback was created.** Preserve exact source v1.0 and 29 immutable APL revision hashes.
