## Exact current published release and differences

- [Hekili Forever v0.10.0](https://github.com/zmsl/hekili/releases/tag/v0.10.0) was published 19 November 2026, 14:04 UTC. Pin: `zmsl/hekili@3c2cf3e32472cc807b1ba29d992fc13a273da8ee`. Previous published comparator: v0.9.0 `8f95f2ea0a45428554c1e938ed7357b870030514`. GitHub tagged diff has 118 upstream commits, including engine/state/resources, warning, WoWSims default priorities and regression changes.
- The [published Guardian default](https://github.com/zmsl/hekili/blob/v0.10.0/src/Hekili_Druid/APLs/Guardian%20(wowsims.com).simc) drops Swipe and omits Barkskin/Frenzied Regeneration due to unknown player health. This is a **shipped default change, not a removal of Swipe from the class**.
- [Official Forever APL condition support](https://github.com/zmsl/hekili/blob/v0.10.0/docs/wiki/APL-Conditions-On-Forever.md): `health.pct` is effectively 100 in combat; `incoming_damage_<N>s` reads 0; hidden Rage is an estimated band; `action.<key>.in_range` is read from the client. Do not use secret player health to trigger a defensive or claim to measure tank mitigation.
- [Druid class source](https://github.com/zmsl/hekili/blob/v0.10.0/src/Hekili_Druid/Druid.lua) retains `barkskin` (22812), `frenzied_regeneration` (22842), `swipe_bear` (779), Demoralising Roar. Guardian v1.2 Draft's ready/Defensives ON/in-melee Barkskin is **proactive**, not low-health triage. Its timing could waste a defensive; player/encounter proof remains necessary before promotion. Frenzied Regeneration remains manual pending honest, observable conditions.
- [Hunter class source](https://github.com/zmsl/hekili/blob/v0.10.0/src/Hekili_Hunter/Hunter.lua) still registers main pet recovery (Call Pet 883, Revive Pet 982), Summon Hawk (1293241), Bestial Wrath and a modelled two-Hawk limit. `pet.hawk.count` means modelled guardians, not actual main-pet arrival. The released native pet fixture still cannot prove accepted Call/Revive and three real state transitions.
- Our two generic all-role native fixtures had `APLFOREVER_SOURCE_RELEASE == "v0.9.0"` to select renamed BM/MM Turret worlds. That is an **actual release-harness defect** on v0.10.0: it would try retired `BeastMastery` and `Marksmanship` fixtures. Change only the version-aware fixture selector for v0.9.0 **and later**, preserve older version fixtures and reject invalid version strings. **No gameplay APL changes**.
